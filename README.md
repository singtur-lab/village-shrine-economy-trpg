# 村の神社 経済TRPG

村の共同体が銀行・交易・投資・還元契約を使い、暮らしと経済を育てるチャットTRPGの独立企画です。これは [異世界村育成TRPG](https://github.com/singtur-lab/village-game) とは別作品です。

## 現在の状態

- **段階:** 企画・検証準備
- **仕様:** 仮仕様とチャット用GMプロンプトを作成。初期ルール原本は未入手。Meta AIでのプレイをまとめたユーザー提供資料を根拠区分付きで保管しています。
- **アプリ:** チャット専用を想定。HTML試作は置いていません。
- **公開:** ルールの出典・権利・数値の確認前なので非公開です。

## この作品で検討する遊び

銀行の健全性、地域間の融資と交易、外へ出る人との還元契約、共同体の透明性を扱います。資産を増やすだけでなく、「豊かになった共同体が何を大切にするか」を問う設計を目指します。

## 主要ドキュメント

- `docs/DESIGN_BRIEF_v0.1.md` — 企画の核と設計方針
- `docs/SPEC_ALPHA_v0.1.md` — プレイテスト用の仮仕様
- `prompts/MASTER_PROMPT_v0.1.md` — 新しいチャットを起動するGMプロンプト

## 資料の読み方

`research/meta-response/`には受け取った4つの資料を保存しています。ログの原本そのものではなく、報告資料の内容を独立に検証したものでもありません。設計では、会話ログで確認された事実、資料上の主張、GMの推定・即興、改善提案を分けます。
